# Скриншоты инструкции

Файлы из этой папки подставляются в страницу `/help` по путям вида
`/help/img/<имя>.png`. Пока файла нет, на его месте рисуется пунктирная рамка с
именем и подписью — текст инструкции от этого не ломается.

## Правила

- **Один комплект на все языки.** Скриншоты снимаются на русском интерфейсе, а
  переводятся только подписи под ними. Иначе каждый мелкий правок UI пришлось бы
  переснимать трижды.
- **Выноски рисует скрипт, а не рука.** Чистые кадры лежат в
  `apps/web_app/help-src/img-raw/`, координаты кружков — в
  `apps/web_app/help-src/annotate.py`. Скрипт всегда читает исходники и
  перезаписывает эту папку, поэтому его можно гонять сколько угодно раз:

  ```
  cd apps/web_app && python3 help-src/annotate.py
  ```

  Номера кружков обязаны совпадать с нумерованным списком под картинкой во всех
  трёх языковых версиях главы. Меняете список — правьте координаты, и наоборот.
- **Личные данные замазывает тот же скрипт** — таблица `REDACT`. Так замазаны
  почты владельцев и выданные им пароли на `panel-users.png`: папка `public/`
  уезжает на Vercel целиком, и файл доступен по прямой ссылке кому угодно, даже
  если сама глава видна только суперадмину.
- Планшет — вертикально, панель — окно шириной около 1400 px.
- PNG, ширина 1000–1600 px.
- Имя файла менять нельзя — оно прописано в трёх языковых версиях главы.

## Статус

Экраны планшета сняты в эмуляторе (Pixel 9, дисплей переведён в 1200×1920) на
привязанном тестовом аппарате №100000000 — данные там тестовые, цены по 1–2 ₸.
Экраны панели сняты вручную.

Выноски проставлены на 14 кадрах: `panel-login`, `panel-sales`, `panel-devices`,
`panel-inventory-screen`, `panel-inventory-edit`, `panel-catalog`,
`panel-product-modal`, `panel-users`, `tablet-home`, `tablet-cart`,
`tablet-payment`, `tablet-pairing`, `tablet-login`, `tablet-board`. Остальные кадры подписаны
текстом и нумерации не требуют.

`tablet-dispense.png` снят на живом аппарате: это случай неудачной выдачи —
карточка с пометкой «Возврат» и сумма к возврату.

Не снято и ждёт живого аппарата:

- `panel-inventory-vending.png` — позиции **вендингового** аппарата, сгруппированные
  по полкам, с остатком на кнопках −/+. Присланный кадр оказался микромаркетом с
  экраном (номера ячеек 10–99), поэтому он переименован в
  `panel-inventory-screen.png`, а подписи под ним переписаны под то, что на нём
  действительно видно.

Как пересняться на планшете с компьютера:

```
adb shell wm size 1200x1920 && adb shell wm density 240   # необязательно
adb exec-out screencap -p > tablet-home.png
```

## Что нужно снять

### Панель (браузер)

| Файл | Что на кадре |
|---|---|
| `panel-login.png` | Экран входа: email, пароль, кнопка «Войти» |
| `panel-sales.png` | Вкладка «Продажи»: выбор аппарата, кнопки периода, обновление, плитки «Выручка» и «Заказов» |
| `panel-sale-expanded.png` | Раскрытый чек с позициями, среди них хотя бы одна невыданная с суммой «К возврату» |
| `panel-devices.png` | Список аппаратов: лампочка, бейдж типа, карандаш, «Отвязать планшет» |
| `panel-inventory-screen.png` | Позиции аппарата: кнопка «назад», «Добавить» и «Категории», фильтр категорий, номер ячейки, остаток, цена, действия строки |
| `panel-inventory-edit.png` | Карточка позиции: товар из каталога, номер ячейки или слот, цена, остаток |
| `panel-catalog.png` | Вкладка «Каталог»: фильтры «Активные / Черновики / Архив», кнопка добавления, действия строки |
| `panel-product-modal.png` | Карточка товара: фото, название, категория, объём, эмодзи, описание |
| `panel-users.png` | Вкладка «Администрирование» (снимать под суперадмином): список аккаунтов, раскрытый аккаунт с аппаратами, «Новый пользователь», «Добавить устройство», группа «Устройства без владельца» |

Кадр `panel-users.png` используется в главе «Владельцы и аккаунты» — он же
показывает, откуда начинаются «Добавить устройство» и «Перенести».

### Заводское приложение — папка `delete_factory_app/`

Кадры пуско-наладки: как выйти из китайского «Торгового автомата» и удалить его.
Сняты на аппарате M102/M109E, разметка — рамки вокруг цели (таблица `BOXES`).

| Файл | Что на кадре |
|---|---|
| `main-screen.png` | Главный экран заводского приложения, обведён ID в правом верхнем углу — по нему открывается ввод пароля |
| `password-screen.png` | Нампад ввода пароля: поле и кнопка «ОК» (цифры каждый раз перемешаны) |
| `choose_service-menu.png` | Меню настроек, обведена плитка «Системные настройки» в сетке |
| `choose_other_settings.png` | Системные настройки, обведена плитка «Другие настройки» |
| `show_navbar.png` | Строка «Панель навигации», обведён правый сегмент — «Показать» |
| `delete_factory_app.png` | Список приложений Android, обведён «Торговый автомат» |

Скриншот планшета снимается с устройства: `adb exec-out screencap -p > tablet-home.png`.
