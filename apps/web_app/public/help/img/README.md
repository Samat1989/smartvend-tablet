# Скриншоты инструкции

Файлы из этой папки подставляются в страницу `/help` по путям вида
`/help/img/<имя>.png`. Пока файла нет, на его месте рисуется пунктирная рамка с
именем и подписью — текст инструкции от этого не ломается.

## Правила

- **Один комплект на все языки.** Скриншоты снимаются на русском интерфейсе, а
  переводятся только подписи под ними. Иначе каждый мелкий правок UI пришлось бы
  переснимать трижды.
- **Выноски — на самой картинке.** Кружки ①②③ ставятся поверх скриншота в том
  порядке, в котором идёт нумерованный список под ним в тексте главы.
- Планшет — вертикально, панель — окно шириной около 1400 px.
- PNG, ширина 1000–1600 px. Личные данные (email, телефоны, суммы реальных
  продаж) замазать.
- Имя файла менять нельзя — оно прописано в трёх языковых версиях главы.

## Что нужно снять

### Панель (браузер)

| Файл | Что на кадре |
|---|---|
| `panel-login.png` | Экран входа: email, пароль, кнопка «Войти» |
| `panel-sales.png` | Вкладка «Продажи»: выбор аппарата, кнопки периода, обновление, плитки «Выручка» и «Заказов» |
| `panel-sale-expanded.png` | Раскрытый чек с позициями, среди них хотя бы одна невыданная с суммой «К возврату» |
| `panel-devices.png` | Список аппаратов: лампочка, бейдж типа, карандаш, «Отвязать планшет» |
| `panel-inventory-vending.png` | Позиции вендингового аппарата по полкам: кнопка «назад», фильтр категорий, остаток ±, цена, карандаш |
| `panel-inventory-edit.png` | Карточка позиции: товар из каталога, цена, остаток, слот |
| `panel-catalog.png` | Вкладка «Каталог»: фильтры «Активные / Черновики / Архив», кнопка добавления, действия строки |
| `panel-product-modal.png` | Карточка товара: фото, название, категория, объём, эмодзи, описание |
| `panel-users.png` | Вкладка «Администрирование» (снимать под суперадмином): список аккаунтов, раскрытый аккаунт с аппаратами, «Новый пользователь», «Добавить устройство», группа «Устройства без владельца» |

Кадр `panel-users.png` используется в главе «Владельцы и аккаунты» — он же
показывает, откуда начинаются «Добавить устройство» и «Перенести».
