# Каталог үлгүлөрү жана жаңыртуулар

## Жалпы товарлар

**Каталог** салмасында сизге **ЖАЛПЫ** белгиси бар товарлар көрүнөт — бул кадимки
ээлердин тизмесинде жок үлгүлөр. Алардын картасында **«Жалпы товар (үлгү)»**
белгиси чыгат.

Баштапкы топтом ушул үлгүлөрдөн түзүлөт: каталогу бош ээде **«Баштапкы топтомду
көчүрүү»** баскычы пайда болот да, ал бул карталардын өз көчүрмөлөрүн алат. Андан
ары ал аларды өзүндө оңдойт — сиздин үлгүлөрүңүзгө бул таасир этпейт, кайра
басканда көчүрмө пайда болбойт.

Үлгүлөрдө дээрлик ар бир түйүндө туруучу нерсени кармаңыз: суу, кофе, снэктер —
жакшы сүрөтү менен. Бул жаңы ээнин биринчи кечин үнөмдөйт.

## Планшеттин жаңыртууларын чыгаруу

Релиз репозиторийдин түбүнөн бир буйрук менен чогултулуп жарыяланат:

```
python3 scripts/release_tablet.py --version X.Y.Z --notes "эмне жаңы"
```

Скрипт кол коюлган APK чогултат, тег коёт, файлды жаңыртуулар кампасына жана
GitHub Releases'ке жүктөйт.

Чыгарып жаткан машинада эмне болушу керек:

- `gh auth login` — GitHub'ка жетүү;
- кампанын ачкычы репозиторийдин түбүндөгү `.supabase_key` файлында;
- кол коюу файлы `apps/tablet/android/release.jks` жана жанында `key.properties`.

Кеңири — `apps/tablet/android/README_RELEASE_SIGNING.md`.

## Жаңыртуу аппараттарга кантип жетет

Планшеттер өздөрү жаңырышпайт жана буйрук боюнча өчүп-күйүшпөйт. Жаңы версия
планшетте тейлөө менюсунда көрүнөт: «Тутум жөндөөлөрү» → «Жаңыртуу» →
«Текшерүү».

- **Түзмөктүн ээлик укуктары бар** планшетте орнотуу ашыкча суроосуз өтөт.
- Ал укуктар жок болсо, Android кадимки орнотуу терезесин көрсөтөт жана
  «Орнотуу» дегенди бирөө кол менен басышы керек.

Ошондуктан көптөн бери эч ким келбеген планшет эски версияда калат. Бул кадимки
нерсе: аппарат сатууну улантат, жаңыртуу шашылыш эмес. Ар бир планшеттин версиясы
админ-панелде көрүнөт — «Түзмөктөр» салмасында байланыш лампасына курсорду алып барыңыз.
