# Иштетүү жана жөндөө

Бул бөлүм планшетти аппаратка биринчи жолу орнотуп жаткан адамга арналган. Көбүнчө
бул — ээсинин өзү: атайын билим керек эмес, бирок кабели бар компьютер же экинчи
телефон керек.

## Эмне керек болот

- Планшет жана аппараттын платасына USB-адаптер (адатта CH340).
- Түйүндө Wi-Fi: интернетсиз аппарат төлөмдү кабыл албайт.
- Аппараттын номери жана ачкычы — аларды системанын жеткирүүчүсү берет.
- USB кабели бар компьютер **же** MMD колдонмосу бар телефон.

## 1-кадам. Колдонмону жүктөө

Колдонмонун файлы — кадимки APK. Учурдагы версияга шилтемени системанын
жеткирүүчүсү берет; ал жаңыртуулардын сүрөттөмөсүндө да турат:

```
https://cgvfhtvdtdjsyluhlcbq.supabase.co/storage/v1/object/public/updates/tablet/manifest.json
```

Бул файлдагы `url` талаасы — жаңы APK'га түз шилтеме. Каалаган версияны орнотуу
жетиштүү: андан ары планшет тейлөө менюсунан өзү жаңырат.

## 2-кадам. Заводдук колдонмодон чыгуу

Жаңы аппарат өзү иштеп, бүт экранды ээлеген кытай колдонмосу менен келет. Android
жөндөөлөрүнө жетүү үчүн андан чыгуу керек.

Заводдук колдонмонун баштапкы экранында же башкы экранында жашыруун кирүү бар:
**болжол менен 5 секунд узак басуу** же экрандын бурчтарын — көбүнчө жогорку
тилкени — **катары менен 5 жолу тез басуу**. Жөндөөлөр менюсу ачылып, сырсөз
сурайт.

- Сырсөз аппаратты алгачкы жөндөөдө коюлган — жеткирүүчүдөн сураңыз.
- Сырсөз белгисиз болсо, заводдук колдонмодо күн сайын алмашкан инженердик сырсөз
  бар. Ал планшеттин сериялык номеринен эсептелет; кантип экени
  `docs/02_LIFECYCLE.md` файлынын D.1 бөлүмүндө жазылган.

Ошол эле менюда Android иш столуна чыгуу пункту бар.

> Заводдук менюга кирүү мүмкүн болбосо, айланып өтүү жолу бар: планшетте USB
> аркылуу оңдоону күйгүзүңүз (Жөндөөлөр → Планшет жөнүндө → «Куруу номерин» 7 жолу
> басуу → Иштеп чыгуучулар үчүн) жана андан ары компьютерден иштеңиз — заводдук
> колдонмону `adb shell pm disable-user --user 0 <пакет>` буйругу менен өчүрсө
> болот.

## 3-кадам. Колдонмону орнотуу

**Компьютерден:**

```
adb install -r app-armeabi-v7a-release.apk
```

**Компьютерсиз:** APK'ны планшеттин браузери менен жүктөңүз же флешка менен алып
келип, файл менеджеринен ачыңыз. Android ушул булактан колдонмо орнотууга уруксат
сурайт — уруксат бериңиз.

## 4-кадам. Колдонмону негизги кылуу

Системанын «Үй» баскычын басып, **MicroVend** → **Ар дайым** тандаңыз. Андан кийин
колдонмо планшет күйгөндө иштеп, иш столунун ордуна ачылат.

## 5-кадам. Түзмөктүн ээлик укуктары

Түзмөктүн ээлик укуктары (device owner) Android колдонмого экранды толук бериши
үчүн керек: сатып алуучу витринаны жыйнай албайт, жөндөөлөргө кире албайт, ал эми
жаңыртуулар суроосуз орнотулат.

Бул укуксуз аппарат иштейт, бирок алсызыраак корголот — экранды бекитүүдөн сатып
алуучу эки баскычты кармап туруп чыгат.

**Android шарттары:** планшетте бир да аккаунт болбошу керек жана, эреже катары,
бир гана колдонуучу болушу тийиш. Алгачкы жөндөөдө Google'га кирүүнү өткөрүп жиберүү
жетишсиз — кээ бир прошивкалар өз кызматтык аккаунтун түзөт.

**Кабель менен (негизги ыкма):**

```
adb shell dpm set-device-owner kz.smartvend.m102_tester/.KioskAdminReceiver
adb reboot
```

Буйрук баш тартса, себептердин талдоосу жана айланып өтүү жолдору —
`apps/tablet/docs/03_FLEET_PROVISIONING.md`.

**Телефондон, компьютерсиз:** MMD колдонмосу телефонду Wi-Fi аркылуу ошол эле
куралга айландырат. Тартиби: планшетте «Зымсыз оңдоону» күйгүзүү, MMD'де
«Планшетти туташтыруу», андан соң «Колдонмону орнотуу» жана «Укук берүү».
Кеңири жана планшет табылбаса эмне кылуу керектиги —
`apps/mmd_diag/docs/PROVISIONING.md`.

> Укуктар колдонмо иштегенде бир жолу окулат. Укук берилгенден кийин планшет
> өчүрүп-күйгүзүлмөйүнчө эч нерсе болбогондой сезилет.

Планшет түйүндөн алынганда же жеткирүүчүгө кайтарылганда укуктар тейлөө менюсунан
алынат: «Тутум жөндөөлөрү» → «Ээлик укуктарын алып салуу».

## 6-кадам. Платаны туташтыруу

Планшетти аппараттын платасы менен туташтырып, «Тейлөө режими» → **Плата** ачыңыз.

1. Протоколду тандаңыз:
   - **M102 / M109E** — спиралдары бар заводдук плата. Плата жооп бербесе, M102
     CRC-сырсөзүн күйгүзүп көрүңүз — кээ бир платаларда ал милдеттүү.
   - **BarysVend V27.2** — BarysVend платасы. Моторлор башка уячаларга жооп берсе,
     «Сап ↔ мамыны алмаштыруу» күйгүзүңүз.
   - **Микромаркет** — кулпунун платасы: мотор жок, «Кулпуну ачуу» бар.
2. Портту тандаңыз же **Авто издөө** басыңыз.
3. **Туташтыруу**, андан соң **Байланышты текшерүү** (же **Кулпуну ачуу**) басыңыз.

Ылдыйдагы журналда алмашуу жүрүшү керек. Жооп болбосо — кабелди, жалпы жерди жана
платанын кубатын текшериңиз.

## 7-кадам. Жайгашуу жана товарлар

«Слоттордун жайгашуусунда» аппаратка ылайык үлгүнү тандаңыз же өзүңүздүкүн
чогултуңуз: текчелер, уячалар, уячалардын моторлорго байланышы. Ар бир уячаны
«Моторлорду жөндөөдөгү» **Текшерүү** баскычы менен текшериңиз.

Андан кийин «Товарларда» кайсы слотто эмне турганын, баасын жана калдыгын коюңуз.
Калганын — сүрөттөрдү жана сүрөттөмөлөрдү — ээси админ-панелден толуктайт.

## 8-кадам. Аппаратты байлоо

![Туташуу экраны](/help/img/tablet-pairing.png)

1. **Аппараттын номери** — цифралар, системанын жеткирүүчүсү берет.
2. **Ачкыч** — ошол аппараттын купуя ачкычы.
3. **O!Акча** белгиси — Кыргызстан үчүн гана коюлат: аппарат сомго жана O!Bank
   капчыгына өтөт. Казакстан үчүн белги керек эмес — төлөм Kaspi аркылуу теңге
   менен болот.
4. Туташуу баскычы.

Номер же ачкыч туура эмес болсо, планшет ошону айтат. «Бул аппаратты башка планшет
колдонуп жатат» деген билдирүү ага башка планшет байланганын билдирет: адегенде
ээси админ-панелде «Планшетти ажыратуу» басышы керек.

## Кетердин алдындагы текшерүү

- Витрина ачылат, товарлар көрүнөт, баалар туура.
- Сыноо сатып алуу өтөт: QR чыгат, төлөм алынат, товар берилет.
- Админ-панелде аппараттын лампасы **жашыл**, сыноо сатуусу «Сатуулар» салмасында
  көрүнөт.
- Планшет өчүрүп-күйгүзүлүп, колдонмого өзү кайтты.
- Колдоо экраны толтурулган: телефон жана иштөө убактысы.
- Тейлөө режиминин PIN коду коюлуп, ээсине берилген.
