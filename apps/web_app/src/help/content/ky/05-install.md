# Иштетүү жана жөндөө

Кыскача версиясы: планшеттен заводдук колдонмону алып салуу, MicroVend орнотуу
жана аппаратты байлоо. Плата, слоттордун жайгашуусу жана Android укуктары тейлөө
режиминде жөндөлөт — «Планшеттин тейлөө режими» бөлүмү; толук иштетүү сүрөттөмөсү
кийинчерээк жазылат.

## Эмне керек болот

- Планшет жана аппараттын платасына USB-адаптер (адатта CH340).
- Түйүндө Wi-Fi: интернетсиз аппарат төлөмдү кабыл албайт.
- Аппараттын номери жана ачкычы — аларды системанын жеткирүүчүсү берет.

## 1-кадам. Заводдук колдонмону алып салуу

Жаңы аппарат кытай колдонмосу менен келет: ал өзү иштеп, бүт экранды ээлейт. Андан
Android иш столуна чыгуу керек — экран сактагычта же башкы экранда жашыруун кирүү
бар: жогорку тилкени **болжол менен 5 секунд басып туруу** же **катары менен
5 жолу тез басуу**. Меню сырсөз сурайт, аны системанын жеткирүүчүсү билет; ошол
эле жерде иш столуна чыгуу бар.

Андан ары заводдук колдонмону таптакыр өчүргөн жакшы, антпесе кайра күйгүзгөндөн
кийин ал экранды кайрадан ээлейт: Android жөндөөлөрү → Колдонмолор → заводдук
колдонмо → **Өчүрүү** же баскычы болсо **Жоюу**.

## 2-кадам. MicroVend орнотуу

Планшетте жүктөө барагын ачып, APK жүктөп алыңыз:

```
https://smartvend.kz/mm
```

Android бул булактан колдонмо орнотууга уруксат сурайт — уруксат бериңиз.
Орноткондон кийин MicroVend'ди ачып, аны башкы экран кылыңыз: Android лаунчер
тандоону сунуштайт — MicroVend жана **Ар дайым** дегенди тандаңыз. Каалаган
версияны орнотсо болот: андан ары планшет тейлөө менюсунан өзү жаңырат.

## 3-кадам. Аппаратты байлоо

![Туташуу экраны](/help/img/tablet-pairing.png)

1. **Аппараттын номери** — цифралар, системанын жеткирүүчүсү берет.
2. **Ачкыч** — ошол аппараттын купуя ачкычы.
3. **O!Акча** белгиси — Кыргызстан үчүн гана коюлат: аппарат сомго жана O!Bank
   капчыгына өтөт. Казакстан үчүн белги керек эмес — төлөм Kaspi аркылуу теңге
   менен болот.
4. Туташуу баскычы.

Номер же ачкыч туура эмес болсо, планшет ошону айтат. «Бул аппаратты башка планшет
колдонуп жатат» деген билдирүү ага башка планшет байланганын билдирет: адегенде
ээси админ-панелде «Планшетти ажыратуу» басышы керек.

## Кетердин алдындагы текшерүү

- Витрина ачылат, товарлар көрүнөт, баалар туура.
- Сыноо сатып алуу өтөт: QR чыгат, төлөм алынат, товар берилет.
- Админ-панелде аппараттын лампасы **жашыл**, сыноо сатуусу «Сатуулар» салмасында
  көрүнөт.
- Планшет өчүрүп-күйгүзүлүп, колдонмого өзү кайтты.
- Колдоо экраны толтурулган: телефон жана иштөө убактысы.
- Тейлөө режиминин PIN коду коюлуп, ээсине берилген.
