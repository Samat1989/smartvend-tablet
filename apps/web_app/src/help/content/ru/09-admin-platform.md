# Шаблоны каталога и обновления

## Библиотека фото товаров

Общего каталога товаров больше нет: каждый владелец ведёт свой. Общей осталась
только **библиотека фото** — когда владелец создаёт товар, в карточке есть
кнопка **Выбрать готовое фото**, и он ищет снимок по названию вместо того,
чтобы фотографировать ту же бутылку сам.

Фото лежат в хранилище один раз, у всех владельцев ссылка на них одинаковая —
поэтому планшеты скачивают каждое фото один раз на весь парк.

Пополнить библиотеку — из корня репозитория:

```
python3 scripts/import_photo_library.py --source ~/photos --dry-run
python3 scripts/import_photo_library.py --source ~/photos
```

Первая команда только показывает, что будет загружено. Одинаковые снимки
схлопываются в один, а повторный запуск ничего не загружает заново.

## Выкатка обновлений планшета

Релиз собирается и публикуется одной командой из корня репозитория:

```
python3 scripts/release_tablet.py --version X.Y.Z --notes "что нового"
```

Скрипт соберёт подписанный APK, поставит тег, зальёт файл в хранилище обновлений
и в GitHub Releases.

Установщики скачивают приложение со страницы <https://smartvend.kz/mm> — после
релиза проверьте, что там лежит свежая версия.

Что нужно на машине, откуда выкатываете:

- `gh auth login` — доступ к GitHub;
- ключ хранилища в файле `.supabase_key` в корне репозитория;
- файл подписи `apps/tablet/android/release.jks` и `key.properties` рядом с ним.

Подробности — `apps/tablet/android/README_RELEASE_SIGNING.md`.

## Как обновление доходит до аппаратов

Планшеты не обновляются сами и не перезагружаются по команде. Новая версия видна
на планшете в сервисном меню: «Системные настройки» → «Обновление» → «Проверить».

- На планшете **с правами владельца устройства** установка проходит без вопросов.
- Без этих прав Android покажет обычное окно установки, и кто-то должен нажать
  «Установить» руками.

Поэтому планшет, к которому давно никто не подходил, останется на старой версии.
Это нормально: аппарат продолжает продавать, обновление не срочное. Версию
каждого планшета видно в админ-панели — наведите курсор на подпись связи в разделе
«Устройства».
