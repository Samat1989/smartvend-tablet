# Пуско-наладка

Глава для того, кто ставит планшет на аппарат в первый раз. Часто это сам
владелец — специальных знаний не нужно, но нужен компьютер с кабелем или второй
телефон.

## Что понадобится

- Планшет и USB-переходник к плате аппарата (обычно CH340).
- Wi-Fi на точке: без интернета аппарат не примет оплату.
- Номер аппарата и ключ — их выдаёт администратор платформы.
- Компьютер с кабелем USB **или** телефон с приложением MMD.

## Шаг 1. Скачать приложение

Файл приложения — обычный APK. Ссылку на актуальную версию даёт администратор
платформы; она же лежит в описании обновлений:

```
https://cgvfhtvdtdjsyluhlcbq.supabase.co/storage/v1/object/public/updates/tablet/manifest.json
```

В этом файле поле `url` — прямая ссылка на свежий APK. Достаточно поставить
любую версию: дальше планшет обновляется сам из сервисного меню.

## Шаг 2. Выйти из заводского приложения

Новый аппарат приезжает с китайским приложением, которое запускается само и
занимает весь экран. Из него нужно выйти, чтобы добраться до настроек Android.

На заставке или на главном экране заводского приложения есть скрытый вход:
**долгое нажатие около 5 секунд** или **5 быстрых нажатий подряд** по углам
экрана — обычно по верхней полосе. Открывается меню настроек, и оно спрашивает
пароль.

- Пароль задавался при первичной настройке аппарата — спросите поставщика.
- Если пароль неизвестен, у заводского приложения есть инженерный пароль,
  который меняется каждый день. Его считают из серийного номера планшета; как
  именно — описано в `docs/02_LIFECYCLE.md`, раздел D.1.

В том же меню есть пункт выхода на системный рабочий стол Android.

> Если войти в заводское меню не получается, есть обходной путь: включите на
> планшете отладку по USB (Настройки → О планшете → 7 раз по «Номер сборки» →
> Для разработчиков) и дальше работайте с компьютера — заводское приложение
> можно просто отключить командой `adb shell pm disable-user --user 0 <пакет>`.

## Шаг 3. Установить приложение

**С компьютера:**

```
adb install -r app-armeabi-v7a-release.apk
```

**Без компьютера:** скачайте APK браузером планшета или принесите на флешке и
откройте через файловый менеджер. Android спросит разрешение ставить приложения
из этого источника — разрешите.

## Шаг 4. Сделать приложение главным

Нажмите системную кнопку «Домой» и выберите **MicroVend** → **Всегда**. После
этого приложение запускается при включении планшета и открывается вместо
рабочего стола.

## Шаг 5. Права владельца устройства

Права владельца устройства (device owner) нужны, чтобы Android отдал приложению
экран целиком: покупатель не свернёт витрину и не залезет в настройки, а
обновления ставятся без вопросов.

Без этих прав аппарат работает, но защищён слабее — из закрепления экрана
покупатель выходит удержанием двух кнопок.

**Условия Android:** на планшете не должно быть ни одного аккаунта и, как
правило, должен быть один пользователь. Пропустить вход в Google при первичной
настройке недостаточно — некоторые прошивки заводят собственный служебный
аккаунт.

**Кабелем (основной способ):**

```
adb shell dpm set-device-owner kz.smartvend.m102_tester/.KioskAdminReceiver
adb reboot
```

Если команда отказывает, разбор причин и обходные пути — в
`apps/tablet/docs/03_FLEET_PROVISIONING.md`.

**С телефона, без компьютера:** приложение MMD превращает телефон в тот же
инструмент по Wi-Fi. Порядок: на планшете включить «Беспроводную отладку», в
MMD нажать «Подключить планшет», затем «Установить приложение» и «Выдать
права». Подробности и что делать, если планшет не находится, —
`apps/mmd_diag/docs/PROVISIONING.md`.

> Права читаются один раз при запуске приложения. Пока планшет не перезагрузился
> после выдачи прав, кажется, что ничего не произошло.

Когда планшет отдают из точки или возвращают поставщику, права снимаются в
сервисном меню: «Системные настройки» → «Снять права владельца».

## Шаг 6. Подключить плату

Соедините планшет с платой аппарата и откройте «Сервисный режим» → **Плата**.

1. Выберите протокол:
   - **M102 / M109E** — заводская плата со спиралями. Если плата не отвечает,
     попробуйте включить CRC-пароль M102 — на части плат он обязателен.
   - **BarysVend V27.2** — плата BarysVend. Если моторы отзываются не на те
     ячейки, включите «Ряд ↔ колонка местами».
   - **Микромаркет** — плата замка: моторов нет, есть «Открыть замок».
2. Выберите порт или нажмите **Автопоиск**.
3. Нажмите **Подключить** и затем **Тест связи** (или **Открыть замок**).

В журнале внизу должен пойти обмен. Если ответов нет — проверьте кабель, общую
землю и питание платы.

## Шаг 7. Раскладка и товары

В «Раскладке слотов» выберите шаблон, подходящий аппарату, или соберите свой:
полки, ячейки, привязка ячеек к моторам. Проверьте каждую ячейку кнопкой
**Тест** в «Настройке моторов».

Затем в «Товарах» проставьте, что в каком слоте стоит, цену и остаток.
Всё остальное — фото и описания — владелец доделает из админ-панели.

## Шаг 8. Привязать аппарат

![Экран подключения](/help/img/tablet-pairing.png)

1. **Номер аппарата** — цифры, выдаёт администратор платформы.
2. **Ключ** — секретный ключ того же аппарата.
3. Галочка **O!Деньги** — ставится только для Кыргызстана: аппарат перейдёт на
   сомы и на кошелёк O!Bank. Для Казахстана галочка не нужна — оплата пойдёт
   через Kaspi в тенге.
4. Кнопка подключения.

Если номер или ключ неверны, планшет так и скажет. Сообщение «аппарат уже
используется» означает, что к нему привязан другой планшет: сначала владелец
должен нажать в админ-панели «Отвязать планшет».

## Проверка перед уходом

- Витрина открывается, товары видны, цены верные.
- Тестовая покупка проходит: QR появляется, оплата списывается, товар выдаётся.
- В админ-панели у аппарата **зелёная** лампочка, а тестовая продажа видна во вкладке
  «Продажи».
- Планшет перезагружен и сам поднялся в приложение.
- Экран поддержки заполнен: телефон и часы работы.
- PIN сервисного режима задан и передан владельцу.
