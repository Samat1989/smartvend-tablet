# Каталог үлгілері және жаңартулар

## Тауар фотоларының кітапханасы

Ортақ тауар каталогы енді жоқ: әр ие өзінікін жүргізеді. Ортақ болып тек **фото
кітапханасы** қалды — ие тауар құрғанда карточкада **Дайын фотоны таңдау**
түймесі бар, және ол сол бөтелкені өзі суретке түсірудің орнына суретті атауы
бойынша іздейді.

Фотолар қоймада бір рет жатыр, барлық иелерде оларға сілтеме бірдей — сондықтан
планшеттер әр фотоны бүкіл паркке бір рет жүктейді.

Кітапхананы толықтыру — репозиторийдің түбірінен:

```
python3 scripts/import_photo_library.py --source ~/photos --dry-run
python3 scripts/import_photo_library.py --source ~/photos
```

Бірінші команда тек не жүктелетінін көрсетеді. Бірдей суреттер біреуге
біріктіріледі, ал қайта іске қосу ештеңені қайта жүктемейді.

## Планшет жаңартуларын шығару

Релиз репозиторийдің түбірінен бір командамен жиналып жарияланады:

```
python3 scripts/release_tablet.py --version X.Y.Z --notes "не жаңа"
```

Скрипт қол қойылған APK жинайды, тег қояды, файлды жаңартулар қоймасына және
GitHub Releases-ке жүктейді.

Орнатушылар қосымшаны <https://smartvend.kz/mm> бетінен жүктейді — релизден кейін
сол жерде жаңа нұсқа тұрғанын тексеріңіз.

Шығаратын машинада не болуы керек:

- `gh auth login` — GitHub-қа қолжетімділік;
- қойма кілті репозиторий түбіндегі `.supabase_key` файлында;
- қол қою файлы `apps/tablet/android/release.jks` және қасында `key.properties`.

Толығырақ — `apps/tablet/android/README_RELEASE_SIGNING.md`.

## Жаңарту аппараттарға қалай жетеді

Планшеттер өздері жаңармайды және команда бойынша қайта қосылмайды. Жаңа нұсқа
планшетте сервистік мәзірде көрінеді: «Жүйелік параметрлер» → «Жаңарту» →
«Тексеру».

- **Құрылғы иесінің құқықтары бар** планшетте орнату артық сұрақсыз өтеді.
- Ол құқықсыз Android әдеттегі орнату терезесін көрсетеді, «Орнату» дегенді
  біреу қолмен басуы керек.

Сондықтан ұзақ уақыт ешкім келмеген планшет ескі нұсқада қалады. Бұл қалыпты:
аппарат сатуын жалғастырады, жаңарту шұғыл емес. Әр планшеттің нұсқасы админ-панельде
көрінеді — «Құрылғылар» бөлімінде байланыс жазуына меңзерді апарыңыз.
