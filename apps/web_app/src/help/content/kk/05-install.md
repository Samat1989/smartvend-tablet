# Іске қосу және баптау

Бұл тарау планшетті аппаратқа бірінші рет орнатып жатқан адамға арналған. Көбіне
бұл — иесінің өзі: арнайы білім керек емес, бірақ кабелі бар компьютер немесе
екінші телефон қажет.

## Не қажет болады

- Планшет және аппараттың платасына арналған USB-адаптер (әдетте CH340).
- Нүктедегі Wi-Fi: интернетсіз аппарат төлемді қабылдамайды.
- Аппараттың нөмірі мен кілті — оларды платформа әкімшісі береді.
- USB кабелі бар компьютер **немесе** MMD қосымшасы бар телефон.

## 1-қадам. Қосымшаны жүктеу

Қосымшаның файлы — кәдімгі APK. Ағымдағы нұсқаға сілтемені платформа әкімшісі
береді; ол жаңартулар сипаттамасында да тұрады:

```
https://cgvfhtvdtdjsyluhlcbq.supabase.co/storage/v1/object/public/updates/tablet/manifest.json
```

Бұл файлдағы `url` өрісі — жаңа APK-ға тікелей сілтеме. Кез келген нұсқаны орнату
жеткілікті: әрі қарай планшет сервистік мәзірден өзі жаңарады.

## 2-қадам. Зауыттық қосымшадан шығу

Жаңа аппарат өзі іске қосылып, бүкіл экранды алатын қытай қосымшасымен келеді.
Android параметрлеріне жету үшін одан шығу керек.

Зауыттық қосымшаның бастапқы экранында немесе басты экранында жасырын кіру бар:
**шамамен 5 секунд ұзақ басу** немесе экранның бұрыштарын — әдетте жоғарғы
жолақты — **қатарынан 5 рет жылдам басу**. Параметрлер мәзірі ашылып, құпия сөз
сұрайды.

- Құпия сөз аппаратты бастапқы баптау кезінде қойылған — жеткізушіден сұраңыз.
- Құпия сөз белгісіз болса, зауыттық қосымшада күн сайын ауысатын инженерлік
  құпия сөз бар. Ол планшеттің сериялық нөмірінен есептеледі; қалай екені
  `docs/02_LIFECYCLE.md` файлының D.1 бөлімінде жазылған.

Сол мәзірде Android жұмыс үстеліне шығу тармағы бар.

> Зауыттық мәзірге кіру мүмкін болмаса, айналып өту жолы бар: планшетте USB
> арқылы жөндеуді қосыңыз (Параметрлер → Планшет туралы → «Құрастыру нөмірін»
> 7 рет басу → Әзірлеушілерге) және әрі қарай компьютерден жұмыс істеңіз —
> зауыттық қосымшаны `adb shell pm disable-user --user 0 <пакет>` командасымен
> өшіруге болады.

## 3-қадам. Қосымшаны орнату

**Компьютерден:**

```
adb install -r app-armeabi-v7a-release.apk
```

**Компьютерсіз:** APK-ны планшеттің браузерімен жүктеңіз немесе флешкамен әкеліп,
файл менеджерінен ашыңыз. Android осы көзден қосымша орнатуға рұқсат сұрайды —
рұқсат беріңіз.

## 4-қадам. Қосымшаны негізгі ету

Жүйенің «Үй» түймесін басып, **MicroVend** → **Әрқашан** таңдаңыз. Содан кейін
қосымша планшет қосылғанда іске қосылып, жұмыс үстелінің орнына ашылады.

## 5-қадам. Құрылғы иесінің құқықтары

Құрылғы иесінің құқықтары (device owner) Android қосымшаға экранды толық беруі
үшін керек: сатып алушы витринаны жинай алмайды, параметрлерге кіре алмайды, ал
жаңартулар сұраусыз орнатылады.

Бұл құқықсыз аппарат жұмыс істейді, бірақ қорғанысы әлсіз — экранды бекітуден
сатып алушы екі түймені ұстап тұрып шығады.

**Android шарттары:** планшетте бірде-бір аккаунт болмауы керек және әдетте бір
ғана пайдаланушы болуы тиіс. Бастапқы баптауда Google-ға кіруді өткізіп жіберу
жеткіліксіз — кейбір прошивкалар өз қызметтік аккаунтын жасайды.

**Кабельмен (негізгі әдіс):**

```
adb shell dpm set-device-owner kz.smartvend.m102_tester/.KioskAdminReceiver
adb reboot
```

Команда бас тартса, себептердің талдауы мен айналып өту жолдары —
`apps/tablet/docs/03_FLEET_PROVISIONING.md`.

**Телефоннан, компьютерсіз:** MMD қосымшасы телефонды Wi-Fi арқылы сол құралға
айналдырады. Тәртібі: планшетте «Сымсыз жөндеуді» қосу, MMD-де «Планшетті қосу»,
содан кейін «Қосымшаны орнату» және «Құқық беру». Толығырақ және планшет
табылмаса не істеу керектігі — `apps/mmd_diag/docs/PROVISIONING.md`.

> Құқықтар қосымша іске қосылғанда бір рет оқылады. Құқық берілгеннен кейін
> планшет қайта қосылмағанша ештеңе болмағандай көрінеді.

Планшетті нүктеден алғанда немесе жеткізушіге қайтарғанда құқықтар сервистік
мәзірден алынады: «Жүйелік параметрлер» → «Иесі құқықтарын алып тастау».

## 6-қадам. Платаны қосу

Планшетті аппараттың платасымен жалғап, «Сервистік режим» → **Плата** ашыңыз.

1. Хаттаманы таңдаңыз:
   - **M102 / M109E** — серіппелері бар зауыттық плата. Плата жауап бермесе,
     M102 CRC-құпия сөзін қосып көріңіз — кейбір платаларда ол міндетті.
   - **BarysVend V27.2** — BarysVend платасы. Моторлар басқа ұяшықтарға жауап
     берсе, «Жол ↔ баған орындарын ауыстыру» қосыңыз.
   - **Микромаркет** — құлып платасы: моторлар жоқ, «Құлыпты ашу» бар.
2. Портты таңдаңыз немесе **Автоіздеу** басыңыз.
3. **Қосу**, содан соң **Байланысты тексеру** (немесе **Құлыпты ашу**) басыңыз.

Төмендегі журналда алмасу жүруі тиіс. Жауап болмаса — кабельді, ортақ жерді және
платаның қуатын тексеріңіз.

## 7-қадам. Орналасу және тауарлар

«Слоттар орналасуында» аппаратқа сай үлгіні таңдаңыз немесе өзіңіздікін
құрастырыңыз: сөрелер, ұяшықтар, ұяшықтардың моторға байлануы. Әр ұяшықты
«Моторларды баптаудағы» **Тексеру** түймесімен тексеріңіз.

Содан кейін «Тауарларда» қай слотта не тұрғанын, бағасы мен қалдығын қойыңыз.
Қалғанын — фото мен сипаттамаларды — иесі админ-панельден толықтырады.

## 8-қадам. Аппаратты байлау

![Қосылу экраны](/help/img/tablet-pairing.png)

1. **Аппараттың нөмірі** — цифрлар, платформа әкімшісі береді.
2. **Кілт** — сол аппараттың құпия кілті.
3. **O!Ақша** құсбелгісі — тек Қырғызстан үшін: аппарат сомға және O!Bank
   әмиянына көшеді. Қазақстан үшін құсбелгі керек емес — төлем Kaspi арқылы
   теңгемен жүреді.
4. Қосылу түймесі.

Нөмір не кілт дұрыс болмаса, планшет солай айтады. «Бұл аппаратты басқа планшет
қолданып жатыр» деген хабарлама аппаратқа басқа планшет байланғанын білдіреді:
алдымен иесі админ-панельде «Планшетті ажырату» басуы керек.

## Кетер алдындағы тексеру

- Витрина ашылады, тауарлар көрінеді, бағалар дұрыс.
- Сынақ сатып алу өтеді: QR шығады, төлем алынады, тауар беріледі.
- Админ-панельде аппараттың шамы **жасыл**, сынақ сатылымы «Сатылымдар» қойындысында
  көрінеді.
- Планшет қайта қосылып, қосымшаға өзі оралды.
- Қолдау экраны толтырылған: телефон және жұмыс уақыты.
- Сервистік режимнің PIN коды қойылып, иесіне берілген.
